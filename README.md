# FeedGuard public website

Public marketing website for FeedGuard, a SkyDev SaaS product for safer supplier feed validation.

## Purpose

- Product information
- Beta plan information
- Lemon Squeezy and business verification
- Future public landing page

## Local usage

Open `index.html` directly, or serve the directory with any simple static file server.

## Deployment

The site is designed for zero-build static deployment on Vercel.
